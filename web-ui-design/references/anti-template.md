# Anti-Template Review

Aim for a recognizable product interface, not novelty for its own sake. Start from the user's brief and actual content. For each familiar treatment, ask what job it does:

- Does this card group information that belongs together?
- Does this divider clarify hierarchy or alignment?
- Does the shadow communicate a layer or an interaction?
- Does the badge convey a meaningful state?
- Does the gradient, glass, oversized type, or animation fit this product?
- Would different typography or composition improve clarity or identity?

Repeated identical cards, indiscriminate gradients or shadows, one radius everywhere, default type choices, a copied hero composition, decorative labels, emoji used as structural icons, and effects on every section are common generated defaults. They can still be right when the brief supports them. Do not replace one fashionable template with its opposite. Spend emphasis deliberately and keep the primary task legible.
