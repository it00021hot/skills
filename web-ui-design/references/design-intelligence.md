# Design Intelligence

Use design catalogues as a way to compare choices, not as a generator that decides the interface for you.

## A useful sequence

1. Identify the product type, audience, primary task, brand signals, and content density.
2. Search for a small set of relevant visual directions, palettes, type pairings, chart approaches, and implementation notes.
3. Reject any result that does not fit the brief, repository, or accessibility needs.
4. Pick a coherent subset and express it through the project’s tokens and components.
5. Review at page level for consistency and at component level for interaction states.

Keep searches narrow and evidence-based. Do not invent catalogue output, claim a recommendation came from a search that was not run, or retry an empty query indefinitely. A search result is a candidate. It does not authorize replacing an established design system or brand without the user asking.

## What the audited catalogues contribute

UI UX Pro Max includes product/style reasoning profiles, palettes, type pairings, chart guidance, stack-specific notes, UX rules, and searchable icon/font data. Its quick reference gives useful web checks for keyboard access, contrast, focus, forms, responsive reflow, motion, loading, chart summaries, and data alternatives. Its catalogs and numeric suggestions are dated snapshots; confirm evolving standards and library APIs from their primary sources.

The Frontend UI/UX Skill contributes a broader review frame: user experience heuristics, consistent visual systems, semantic architecture, WCAG 2.2 AA, and performance. It recommends looking at keyboard behavior, enlarged text/zoom, responsive behavior, color-only meaning, reduced motion, image stability, and actual browser performance. Apply its anti-pattern list as a set of questions, not a blacklist.

## Style families from the desktop pack

The audited pack covers glass, dark developer, minimal sidebar, command palette, card dashboard, neumorphic, Fluent Windows, split workspace, Kanban, terminal plus GUI, floating tool, workspace, settings, data table admin, AI chat plus tools, classic Windows, cyberpunk HUD, neo-brutalism, and claymorphism. Each family has a distinct product use. Borrow only the elements that the user's direction calls for; do not transplant the pack’s repeated measurements, fixed palettes, or same component recipe onto every product.

Use the existing repository's components and tokens to implement the chosen direction. For current standards, browser behavior, and framework APIs, verify against official primary documentation.
