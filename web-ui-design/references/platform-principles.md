# Platform Principles

Apple's Human Interface Guidelines are a useful lens for clarity, user control, feedback, consistency, accessibility, and platform fit. Apply those ideas in the target platform's own language and in the product's visual identity.

Do not default to Apple typography, white space, translucent material, rounded shapes, pill controls, or Apple-like landing pages. Use the current official [Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/) for a specific Apple-platform decision. This skill retains source links and audit notes rather than reproducing Apple-owned HIG text.
