# 测试策略

本文件是 dev-habits 门禁域之一（T2 硬性）。条款身份为方括号短名，引用约定见 SKILL.md 导语；与 SKILL.md 冲突按仲裁阶梯裁决。项目自身约定优先。写测试或修 bug 前必读。

- **[测试与实现同 commit]** 测试与实现同一个 commit 提交，禁"先实现后补测"跨版本漂移；生成代码的测试随生成器模板一起给。
- **[测行为不测实现]** 测试断言对外行为与契约，不测私有实现细节；实现重构不改测试。
- **[边界集固定]** 每个被测单元至少覆盖：空、一个、多个、超限、错误路径；缺一类就是没测完。
- **[外部依赖 mock]** 外部依赖（HTTP、DB、时钟、随机数）用 fake 或 mock 隔离，测试不连真实服务、不依赖执行顺序。
- **[修 bug 先写复现测试]** 修 bug 先写能红的最小复现测试，再修到绿；复现测试留在仓库里防回归。
- **[禁凑覆盖率测试]** 禁为凑覆盖率写的无断言测试、镜像实现的测试；覆盖率是结果不是目标；验证边界见『改完必验证』与『验证不过度』。
