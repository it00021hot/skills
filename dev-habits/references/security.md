# 安全与合规

本文件是 dev-habits 门禁域之一，**T0 不可覆盖**：任何项目约定、成本压力、进度要求都不得降低本节条款。条款身份为方括号短名，引用约定见 SKILL.md 导语。涉及密钥、凭证、外部输入、鉴权、注入面，或引入与升级依赖前必读。

- **[凭证不进代码与日志]** 密钥、token、密码、证书不进代码、配置仓库、日志与报错信息；只从环境变量或密钥管理服务注入；git 历史里出现过的凭证按已泄露处理，先轮换再清理。
- **[外部输入不可信]** 所有外部输入（请求参数、文件、消息体、第三方回调、环境变量）视为不可信，先校验后使用；校验失败返回明确错误，不猜、不静默修正。
- **[查询参数化]** SQL、命令、模板一律参数化，禁字符串拼接；动态标识符（表名、列名、排序字段）用白名单映射，不接受原始输入。
- **[数据删除穿透备份]** 用户数据删除请求必须穿透主库、备份、缓存、日志与衍生数据；只软删主库不算删。
- **[依赖来源审查]** 新依赖引入前审查维护状态、许可证与已知漏洞，选最新稳定版并注明版本；不引入只为一个小功能的重量级依赖；依赖升级按项目节奏批量做，不零敲碎打。
- **[锁文件必提交]** lockfile（go.sum、Cargo.lock、package-lock.json 等）必须提交，保证构建可复现。
