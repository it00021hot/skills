# 数据库与数据操作

本文件是 dev-habits 门禁域之一（T2 硬性）。条款身份为方括号短名，引用约定见 SKILL.md 导语；与 SKILL.md 冲突按仲裁阶梯裁决。项目自身约定优先。建表、写迁移、定事务边界、批量数据操作、改索引前必读。

- **[迁移按序编号]** 数据库迁移按序编号，一个迁移一件事，禁把多个 schema 变更塞进一个文件。
- **[迁移可回滚]** 迁移脚本升级与回滚成对，不留只有升级的迁移；回滚脚本必须真的能跑，不是占位空文件。与『迁移兼容分步』的分工：兼容分步是在线变更的常态机制，回滚是分步失败时的最后手段，两者互补不互替。
- **[迁移兼容分步]** 在线库变更按兼容步骤拆：加列带默认值、删列先停写再删，禁一步到位的破坏性变更；迁移前必须说明对现有数据与流量的影响。
- **[事务边界禁外部 IO]** 事务里禁调外部 API、发消息、写文件；跨系统一致性用本地事务加异步补偿，不拉长事务。
- **[批量操作分批限量]** 大批量数据操作（回填、清理、导出）分批限量执行，每批记日志，支持中断续跑；禁一次性全表操作。
- **[索引随查询评审]** 新查询随评审补索引，禁上线后靠加索引救火；索引变更纳入迁移，说明对应的查询模式。
